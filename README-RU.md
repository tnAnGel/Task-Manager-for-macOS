«Мониторинг системы» неплох, но так и не закрыл потребность до конца — поэтому я сделал
диспетчер задач, которого мне не хватало на Mac. Процессы в плотной сортируемой таблице,
сгруппированные по категориям **Приложения / Фоновые / Системные**, живые колонки
**CPU · Память · Диск · Сеть · GPU** и вкладка «Производительность» с графиками по каждому
ядру. Окно — полностью нативное для macOS (настоящие «светофоры»), раскладка — из Windows 11.

## ✨ Возможности

- 🗂 **Процессы** — группировка по «Приложения / Фоновые / Системные», затем вложенность
  по приложению / одному имени (хелперы Chrome остаются под Chrome). Настоящие иконки,
  суммарные CPU/Память/Сеть, сортируемые колонки, поиск и меню по правому клику
  (завершить, задать приоритет, показать в Finder).
- 📈 **Производительность** — живые графики CPU (сетка по логическим ядрам), памяти, диска,
  сети и GPU, список «топ‑процессов» и важные детали: load average, P/E‑ядра, swap,
  кэшированная память, аптайм, потоки…
- 🧠 **Правильная память** — берётся из `vm_stat`/`sysctl` и точно совпадает с «Мониторингом
  системы» (App + Wired + Compressed, плюс swap и кэш файлов) — то, что большинство
  библиотек на macOS считают неверно.
- 🌐 **Реальные скорости диска и сети** — считаются по системным счётчикам; сеть по
  процессам — через `nettop`.
- 🎮 **Загрузка GPU на Apple Silicon** — читается из `ioreg`, без `sudo`.
- 🚀 **Автозапуск** — Launch Agents / Daemons с человеческими именами, иконками и
  группами по вендору (Adobe, Google, Docker…), плюс включение и отключение.
- 👥 Вкладки **Пользователи · Подробности · Службы** и запуск новой задачи.

## 🚀 Запуск

Понадобится [Node.js](https://nodejs.org/) 18+ и macOS 12 или новее.

**Запуск из исходников**

```bash
git clone https://github.com/tnAnGel/Task-Manager-for-macOS.git
cd TaskManager
npm install
npm start
```

**Сборка `.dmg`** — скрипт сам определит архитектуру вашего Mac:

```bash
./scripts/build.sh
```

…или укажите цель вручную:

```bash
npm run dist:arm64      # Apple Silicon
npm run dist:x64        # Intel
npm run dist:universal  # одно приложение под обе архитектуры
```

Установщик появится в `dist/`. Приложение не подписано, поэтому при первом запуске —
правый клик по нему → **Открыть**, либо:

```bash
xattr -dr com.apple.quarantine "/Applications/Task Manager.app"
```

> **Важно:** при `npm install` Electron скачивает свой рантайм с GitHub. Если вы используете
> блокировщик на уровне DNS (AdGuard, Pi‑hole, VPN…), разрешите `github.com` и
> `objects.githubusercontent.com` или поставьте его на паузу на время установки. Если
> разблокировать GitHub нельзя — используйте зеркало:
> ```bash
> ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/" npm install
> ```

## ⚠️ Заметки и ограничения

Часть метрик macOS не отдаёт так, как Windows:

- **Диск по процессам** требует привилегированных инструментов, поэтому колонка остаётся в `0`.
- **GPU по процессам** недоступен — показывается только общая загрузка GPU.
- Завершение и смена приоритета чужих (или системных) процессов требуют прав и могут молча
  не сработать. Отключение системного Launch Daemon запросит пароль администратора.

## 🛠 Стек

Electron и чистый JS/HTML/CSS — без фронтенд‑фреймворков и сборщиков. Данные о системе
берутся из [`systeminformation`](https://systeminformation.io/) и нескольких нативных утилит
macOS (`vm_stat`, `ioreg`, `nettop`, `launchctl`).
